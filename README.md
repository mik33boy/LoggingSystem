# Logging System

A comprehensive logging and monitoring system built with modern web technologies.

## 🚀 Tech Stack

### Frontend
- [SvelteKit](https://kit.svelte.dev/) - Full-stack framework
- [Flowbite](https://flowbite.com/) - UI component library
- [TailwindCSS](https://tailwindcss.com/) - Utility-first CSS framework
- [FontAwesome](https://fontawesome.com/) - Icon library
- [Tauri](https://tauri.app/) - Desktop application framework

### Backend
- PHP - Server-side scripting
- MySQL - Database management
- XAMPP - Local development environment
- Postman - API testing

## 📋 Prerequisites

- Node.js (Latest LTS version)
- PHP 8.0 or higher
- MySQL 5.7 or higher
- XAMPP
- Composer

## 🛠️ Installation

1. Clone the repository:
```bash
git clone [repository-url]
cd LoggingSystem
```

2. Install frontend dependencies:
```bash
npm install
npm install tailwindcss flowbite flowbite-svelte font-awesome
npm install svelte svelte-chartjs @sveltejs/kit
npm install @tauri-apps/icons
npm install --save-dev @sveltejs/adapter-static @tauri-apps/cli
```

3. Install backend dependencies:
```bash
composer install
composer require phpoffice/phpspreadsheet phpmailer/phpmailer
```

4. Install additional dependencies:
```bash
npm install express mysql body-parser cors
```

## 🚀 Development

To start the development server:
```bash
npm run tauri dev
```
